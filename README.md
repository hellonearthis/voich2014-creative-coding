# creative_coding

This repository is a place where Voich ([@voich2014](https://twitter.com/voich2014)) organizes and republishes **generative art works** that were previously published on a private homepage.
(The private HP was suspended due to the termination of the provider's HP service.)

Works using Web technologies such as HTML / CSS / JavaScript are grouped by folder.
I plan to add new works in the future as I find time.

These works are hobby projects developed at a leisurely pace, so **issues and pull requests are not accepted.** Thank you for your understanding.

Also, the source code is kept in a single HTML file as much as possible so that it is easy for beginners to read.
Commonly used processing is grouped in the `vlib/` folder.
(I am organizing this little by little while engaging in trial and error.)

---

## 📁 Structure

The works in this repository are organized under the `src/` folder:

```
creative_coding/
├── src/
│   ├── vlib/     ← Common Library
│   ├── prac1/    ← Work 1 (e.g. Flower of Arcs Scroll Ver.)
│   └── prac2/    ← Work 2 (To be added in the future)
```

- Each work has its own `index.html` and can be viewed directly from GitHub Pages.
- Common CSS and JavaScript libraries are placed under `vlib/`.
